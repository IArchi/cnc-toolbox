# CNC Toolbox

This project is a small web toolbox created to help CNC users.
It provides tools such as:
 - Feedrate calculator : It computes the appropriate feedrate given the material, the bit and your spindle speed;
 - Carbide Create C2D to G-Code converter : CC no longer allow G-Code export for free users. This tool is a work around;
 - Tiling generator: Your CNC is not long enought to process a full board ? No worries, use tiling !
 - G-Code viewer : Simulate bit moves in 2D or in 3D.

With **Carbide Create 7**, **G-code export is no longer available in the free version**. This project provides a simple alternative by making the conversion accessible directly from a browser.

The online version is available here:
https://iarchi.github.io/cnc-toolbox/
